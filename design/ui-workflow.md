# UI 작업 지침

사용자 요청(2026-10-07): 앞으로 모든 UI 설계·구현·수정·점검에 `.agents/skills/ui-ux-pro-max/SKILL.md`를 포함한다.

- 해당 스킬과 기존 사용자 요구사항을 읽고, 작업에 맞는 UX 또는 WinUI 검색을 수행한다.
- 스킬의 추천은 사용자 요구를 덮어쓰지 않는다. 의도적인 디자인 선택과 구현 오류를 구분한다.
- 기존 폰트·색상·아이콘 에셋을 우선 재사용한다.
- 새 에셋과 UI 방향은 프리뷰로 검토받고 실제 앱에 적용한다.
- Google Drive 기능은 설정 안에 배치한다. 실제 엔진 연결 범위는 `docs/59-native-drive-migration.md`를 따른다.
- 검증 결과에는 네이티브 WinUI와 대화 프리뷰를 구분하고, 확인하지 못한 항목을 명시한다.
