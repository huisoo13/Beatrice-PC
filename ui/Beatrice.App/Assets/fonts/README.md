# Pretendard font assets

- Upstream: https://github.com/orioncactus/pretendard
- Version: 1.3.9, official `Pretendard-1.3.9.zip` release.
- License: SIL Open Font License 1.1; original text is preserved in `OFL.txt`.
- Bundled weights: `Pretendard-Regular.otf` (400), `Pretendard-SemiBold.otf` (600).
- WinUI references these local assets through the sources in `../tokens.json`.
- The fonts are shipped with the application; system-wide installation and runtime downloads are not required.
