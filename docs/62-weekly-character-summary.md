# 캐릭터별 주간 현황 (2026-10-10)

관문 기록과 같은 메인 분류의 서브 메뉴 `주간 현황`에서 볼 수 있습니다. 서브 메뉴 순서는 주간 현황 → 관문 기록 → 보상표입니다.
이번 주는 한국 시간 수요일 06:00 이상, 다음 수요일 06:00 미만입니다. 이전 주 탐색은 기존 관문 기록에서 제공합니다.

## 승인한 디자인
- Pretendard, 기존 공통 색상 에셋 사용. 본문 제목 20px, 날짜 범위 14px.
- 골드·귀속 골드 열 제목은 최상단에 한 번만 표시하며 던전 열 제목은 없습니다.
- 전체 총합 아래에 캐릭터별 영수증을 표시합니다. 직업·캐릭터명·정수 레벨은 한 줄, 캐릭터 합계는 같은 줄 오른쪽에 표시합니다.
- 던전명·난이도·완료 관문과 두 금액을 한 줄로 배치합니다. 관문이 없으면 생략하고, 연속 관문은 1–2관문, 중간이 비면 1·3관문으로 표시합니다.
- 던전 행 최소 높이 32px, 캐릭터 간격 16px. 숫자는 천 단위 구분, 오른쪽 정렬. 긴 텍스트는 줄바꿈하며 고정 사이드바 너비는 유지합니다.

## 집계 기준과 경계
- 엔진이 제공하는 완료 기록을 읽기만 합니다. 진행 중 관문을 추가하지 않으며 저장소나 API를 직접 호출하지 않습니다.
- 같은 캐릭터·던전·난이도의 관문을 묶습니다. 서로 다른 난이도는 별도 내역입니다. 저장소가 관리하는 완료 기록을 합산하며 표시 계층에서 기록을 수정하지 않습니다.
- 일반 골드 = gold − 귀속 골드. 귀속 골드 = 각 관문 gold × bound_percentage의 소수점 버림. 각 관문에서 두 값의 합은 gold와 일치합니다.
- 사용자 결정에 따라 더보기 비용 fee는 차감하지 않습니다. 더보기 실제 감지·차감은 후속 작업입니다.
- 공용 데이터 연결/금액이 없거나 잘못된 내역의 금액은 —입니다. 일부 관문만 연결된 던전도 —로 표시하며, 전체·캐릭터 합계에는 확인된 관문의 금액만 합산합니다. 상단에 미연결 기록 수와 부분 합산 안내를 표시합니다. 미연결 수는 던전 수가 아니라 완료 기록 수입니다.
- 직업과 레벨은 기존 계정 캐릭터 API 캐시를 재사용합니다. 클리어 시점의 레벨이 아닌 캐시 조회 시점 레벨이며 없으면 직업은 —, 레벨은 생략합니다. 새 API 호출 경로는 없습니다.
- 캐릭터는 아이템 레벨 내림차순으로 정렬합니다. 정렬에는 소수점을 포함한 숫자 값을 사용하고 표시는 정수로 유지합니다. 같은 레벨은 기존 최근 기록 순서를 유지하며 레벨이 없거나 잘못된 캐릭터는 마지막에 표시합니다.
- 날짜 해석이 불가능한 기록은 이번 주를 확인할 수 없어 집계에서 제외합니다.
- 주간 경계 변경은 30초 타이머, 기록·공용 데이터·캐릭터 캐시 변경은 기존 스냅샷 갱신으로 반영합니다.

## 골드 이미지 적용 (2026-10-11)
캐릭터명·레벨 뒤 장식 구분선을 제거했습니다. 총합·캐릭터 합계·던전별 금액 왼쪽에는 기존 Drive 공용 이미지 gold.unbound.png / gold.bound.png를 원본 색상으로 표시합니다. 총합은 이미지 16px·금액과 간격 4px, 캐릭터 합계와 던전별 금액은 이미지 14px·간격 2px로 수직 중앙 정렬합니다. 제목에는 이미지를 반복하지 않고, 보상 미연결 —에는 이미지를 붙이지 않습니다.
