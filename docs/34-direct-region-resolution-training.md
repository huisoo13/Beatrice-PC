## 사용자 실게임 확인

2026-09-26 사용자가 고정 좌표 제거 버전을 직접 실행해 테스트한 뒤 정상 동작을 확인했다. 확인 내용: “고정 좌표 제거하고 테스트했는데 잘된다.” 이는 사용자 실게임 확인 결과이며, 시험한 모든 해상도·UI 배율의 구체적인 목록을 추가로 받은 것은 아니다. 아래 자동 재현 검사 결과와 구분해 기록한다. 추가 80% 축소 파생 화면의 OCR 미확정 1건은 알려진 한계로 유지한다.

이번 Git 반영에는 완료 배너 보완, EasyOCR 및 실행 경로의 좌표 의존 제거, 캐릭터 변경 로딩 복구, 다중 해상도 직접 탐지와 관련 문서 29~34의 누적 변경을 포함한다. 학습 모델 바이너리·원본 이미지·진단 출력은 기존 `.gitignore` 정책에 따라 로컬에 보존하며 Git에는 코드·설정·학습 라벨·문서를 반영한다. 다른 PC에서는 아래 해시에 해당하는 모델 파일을 별도로 배치해야 한다.

## 요구사항

- 화면의 미리 지정한 절대 좌표, 메뉴/던전 패널 내부의 고정 비율 OCR 영역을 사용하지 않는다.
- 캐릭터명, 변경 확인 창, 변경 후 로딩, 던전명, 난이도, 관문 상태, 완료 배너를 현재 프레임의 YOLO 탐지로 찾는다.
- 강제 21:9의 상하 검은 여백을 로딩이나 캐릭터 변경으로 해석하지 않는다.
- 탐지가 빠지면 다른 좌표를 읽어 보완하지 않는다. 기존 표시/완료 잠금 정책을 유지하고 새 관측 저장을 보류한다.

## 변경 구조

캐릭터 YOLO는 메뉴·현재 이름 줄·변경 확인 창·대상 이름 줄·로딩 표시 5종을 탐지한다. 메뉴 내부 비율로 Lv 줄을 찾던 경로를 제거했다. 현재 이름 줄의 실제 탐지 박스에서 Lv 접두사만 제거하며 이름 목록을 학습하거나 제한하지 않는다.

던전은 두 단계로 탐지한다. 전체 화면 모델은 패널·관문 행·완료 배너·무관문 헤더 4종을 찾는다. 세부 모델은 YOLO가 찾은 패널 전체를 입력받아 관문 행·던전 이름 줄·난이도 줄·진행 중 아이콘·완료 아이콘·진행 전 아이콘·무관문 제목 줄 7종을 찾는다. 세부 탐지 결과는 패널의 실제 원본 위치를 더해 원본 화면 좌표로 반환한다. 패널 내부의 정해진 비율을 잘라 읽지 않는다.

전체 화면에서 모든 요소를 한 번에 검출하는 초기 후보는 작은 아이콘의 완료 구분과 난이도 줄에서 누락이 있어 채택하지 않았다. 패널 전체를 확대해 다시 YOLO를 실행하면 작은 요소의 픽셀을 더 많이 보존할 수 있다. 관문 없는 레이드의 제목도 직접 탐지하므로 도전 과제 아래 내용 변화로 OCR 위치가 바뀌지 않는다.

관문 아이콘의 위치와 상태는 세부 YOLO가 직접 탐지한다. 이전 320×112 crop과 `(32,112)` 가상 좌표 변환, 위치 오차 crop 재시도, 이전 프레임 영역 재사용은 실행 경로에서 제거했다. 관문 순서는 탐지된 전체 배열의 왼쪽부터 결정하고, 실시간 상태 추적은 해상도 변경에 따른 전체 배열의 이동을 허용한다. 완료 잠금·관문 수 검증·전체 배열 확인 횟수·중복 방지는 유지한다.

동일 위치의 상충하는 관문 상태는 배열 전체를 보류한다. 탐지된 관문 행 끝에 실제 아이콘 크기에 비해 큰 빈 구간이 있으면 바깥 관문 누락으로 보고 저장을 보류한다. 이는 탐지 결과의 기하 관계 검사이며 지정된 화면 위치를 탐색하는 조건이 아니다. 한 글자 줄의 중복 박스는 실제 중첩으로 병합하되 떨어진 후보는 모호한 상태로 남긴다.

무관문 레이드의 내부 단일 상태 슬롯에는 실제 헤더 탐지 박스를 전달한다. 임의의 고정 박스는 만들지 않는다. 배너 단독으로는 레이드 완료 근거가 되지 않으며 현재 프레임의 레이드와 OCR 검증을 요구한다.

글자 전처리의 밝기/색상, 실제 글자 높이에 따른 여백, 탐지 박스 간 포함/중첩 검사, YOLO 입력 크기 변환은 유지한다. 이는 UI가 특정 화면 좌표에 있다고 가정하는 탐색 영역이 아니다.

## 데이터

사용자가 제공한 원본 17장: 메뉴/변경 확인/던전 13장과 로딩 4장. 원본은 `data/raw/direct-regions-0926`에 복사해 보존했다. 1920×1080 및 2508×1411, 일반 비율 및 강제 21:9를 포함한다.

기존 3440×1440 이름·긴 이름·변경·로딩·관문 완료·무관문·일반 퀘스트·제외 콘텐츠 자료를 함께 사용한다. 작은 요소와 완료 아이콘을 보강하기 위해 실제 완료 기록과 전체 프레임 이동/축소 파생 자료를 추가했다. 파생 자료는 독립 검증 데이터가 아니다.

라벨의 박스 좌표는 학습 정답이며 런타임 탐색 좌표로 로드하지 않는다. 이전 crop 모델을 이용한 라벨 초안은 오프라인 전용 도구에서 생성 후 검토했다. 해당 도구는 `tools/legacy_gate_annotations.py`, 설정은 `tools/legacy-gate-regions.json`에 격리했다. 앱 패키지는 이전 관문 crop 모델을 요구하지 않는다.
