# 구원의 종탑 제목 인식과 목록 제한 제거 (2026-10-06)

## 원인

17:16 진단의 구원의 종탑 패널은 부모 YOLO 신뢰도 약 0.94로 탐지됐으나,
짧은 제목의 요소 YOLO 신뢰도가 0.7 기준에 미달해 제목 OCR이 실행되지 않았다.
실제 탐지된 부모 박스를 잘라 요소 모델에 전달하는 구조이며 고정 제목 좌표를
쓰는 것은 아니다. 작은 탐지 박스 변화에 대한 점수 차이는 관측했지만, 이를
독립적인 주원인으로 확정하지 않았다.

기존 `verify_context`에는 난이도 허용 목록이 있었고 `3단계`를 읽어도
거절했다. 사용자의 지시에 따라 던전명·난이도 참고 목록, OCR 사전 제한 기능,
관문 없는 레이드의 특정 난이도 이름 분기를 모두 제거했다. `3단계`만 예외로
등록하는 방식은 사용하지 않는다.

## 변경

- 새 YOLO 글자 영역에서 읽은 이름과 난이도/단계를 그대로 사용한다.
  기존 OCR 2개 이상 일치, 신뢰도 0.65 이상, 유효한 새 탐지 영역 검증은 유지한다.
- 관문 없는 헤더는 난이도 이름 목록 대신 `[표기] 제목`의 구분자로 분리한다.
  구분자가 OCR에서 사라지면 임의로 첫 단어를 난이도로 추측하지 않는다.
- 기존 요소 학습 70장에 종탑의 일반·어두운 패널 두 장을 추가했다.
  일반 패널로 12 epoch, 두 패널을 포함해 6 epoch 추가 학습했다.
  입력 512, freeze 10, batch/nominal batch 2, CPU, AdamW 0.0003이다.
- 요소 모델의 제목 후보 기준은 검증 결과에 맞춰 0.45로 보정했다.
  부모 패널과 다른 요소의 0.7 기준 및 실제 OCR 검증 기준은 유지한다.
- 어두운 단계 글자는 그 탐지 영역의 명암 범위로 정규화한 후 OCR에 전달한다.
  원래 최대 밝기가 110 이상이면 기존 처리와 같다. 화면 좌표를 추가하지 않았다.

## 검증과 적용

- 기존 요소 70장: 이전 69/70, 신규 70/70, 퇴행 0.
- 종탑 보관 파일 6개: 글자가 있는 5개에서 이름/단계 확인, 검은 캡처 1개는
  음성 처리. 학습 원본과 중복 및 같은 플레이의 프레임이 포함된 재현 검사이며
  독립 정확도 측정이 아니다.
- 새 요소 모델로 벨가르딘의 마지막 40장을 실제 OCR/메모리 DB에 재생해
  2관문 완료 저장을 재확인했다.
- 전체 자동 테스트 266개 통과. Windows DPAPI 검사는 일반 사용자 권한에서 실행했다.
- 모델·설정 교체 전 백업과 검사 JSON: `outputs/tower-review-1006/`.
- 학습 라벨: `data/annotations/dungeon-elements-tower-1006.json`.
- 활성 모델 해시는 `config/dungeon-elements.json`에 기록한다.

실제 사용자 DB는 수정하지 않았다. 앱을 완전히 종료하고 재실행해야 새 모델과
목록 제한을 제거한 코드가 적용된다.
