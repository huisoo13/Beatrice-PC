## 현재 인식 구성

YOLO 4개 / 21클래스와 공용 PaddleOCR을 사용한다. 클래스별 역할은 README의
자동 생성 모델 표와 활성 설정을 기준으로 한다. 캐릭터 모델은 `character-dim-1006`이다.
고정 화면 좌표로 OCR 영역을 지정하지 않는다. 학습 명세의 좌표는 라벨이다.

새 선택을 확인하지 못하면 이전 이름으로 확정하지 않는다. 메뉴를 통한 현재 이름
인식도 유지한다. 완료만 DB와 목록에 저장하는 정책과 중복 방지 정책은 유지한다.

## 최초 정리 시점의 검증

- 전체 코드 테스트 262개 통과, README 모델 표 일치 검사 통과.
- 빠른 선택 실패 기록 42프레임에서 마지막 선택 테베체로 입장 후 확정.
  비밀번호 입력 중 어두운 10프레임 모두 올바른 이름을 읽었다.
- 기존 최초 접속 기록 47프레임에서 후이수 확정 유지.
- 기존 화면 127장 중 124장 클래스 구성 일치. 이전 통과 자료의 새 실패와 추가 오탐 없음.
- 실제 기록 DB는 재생 검사에서 수정하지 않았다.

학습에 포함된 실패 기록은 수정 재현 검사이며 독립 정확도 평가가 아니다.
새로운 실사용 화면에 대한 추가 확인과 보존한 던전 클리어 프레임 검토는 남아 있다.
