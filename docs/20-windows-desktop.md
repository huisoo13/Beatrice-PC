# Windows 단일 실행 파일 테스트

`dist/BeatricePC.exe` 하나를 Windows PC로 복사합니다. Python이나 모델 폴더를 따로 복사할 필요가 없습니다. Windows 10/11 x64를 대상으로 구성했습니다. ARM Windows 및 32비트 Windows는 검증 대상이 아닙니다.

## 실행

1. 실행 파일을 더블클릭하고 포함된 파일의 압축 해제가 끝날 때까지 기다립니다. 런타임은 약 2.7GB를 사용하므로 임시 폴더에 충분한 공간이 필요합니다.
2. 로스트아크를 실행합니다. 앱에서 **게임 창 새로고침**을 누르고 대상을 선택합니다.
3. **시작**을 누르고 모델 준비 후 게임으로 돌아갑니다. 내장 OBS 게임 캡처로 프레임을 받습니다. 포커스가 없어도 새 프레임이 공급되면 분석합니다.
4. 게임의 일반 ESC 메뉴를 열고 이름이 여러 번 관측될 시간을 줍니다. 확정까지 걸리는 시간은 PC 성능과 OCR 처리 시간에 따라 달라집니다.
5. 관문 진행 상태에서 완료로 바뀌는 것을 관측하면 PC 시각으로 기록합니다. 이미 완료된 화면에서 시작하면 신규 완료로 기록하지 않습니다.
6. 앱으로 돌아와 캐릭터·던전·난이도·관문·연월일 시각을 확인합니다. 정지 후 **기록 전체 삭제**를 누르면 임시 기록과 중복 방지 이력까지 지웁니다.

기록과 오류 로그는 `%LOCALAPPDATA%\BeatricePC`에 저장됩니다. 실행 파일을 옮기거나 다시 실행해도 같은 PC의 기록은 유지됩니다. EXE 내부에 기록이 들어가는 방식은 아니므로 다른 PC로 기록까지 옮겨지지는 않습니다. 별도 설치 과정은 없지만 실행 중에는 임시 폴더에 포함 파일을 풀어 사용합니다.

## 현재 범위

- UI는 SwiftUI의 메인 스레드처럼 화면 갱신만 담당합니다. QThread 작업자가 모델 초기화, 캡처, 분석, SQLite 기록을 순서대로 실행합니다. 처리 대기 프레임을 쌓지 않고 다음 최신 화면을 가져옵니다.
- 캐릭터가 확정되지 않은 이벤트는 임시 저장합니다. 같은 변경 구간에서 이름이 확정되면 실제 기록으로 전환합니다. 재시작 전 미확정 구간은 새로 보이는 이름으로 임의 배정하지 않습니다.
- 중복 기준은 테스트용입니다. 같은 이름/던전/난이도/관문은 삭제 전까지 한 번 저장하며 주간 초기화는 구현하지 않았습니다. 서버를 구분하는 인식은 아직 없습니다.
- 던전 OCR은 기존 검증 목록 5개 던전, 노말/하드만 승인합니다. 미등록 던전은 자동 기록하지 않습니다.
- 화면 높이 기준으로 좌상단 관문 UI와 화면 중앙 메뉴를 각각 기준 좌표로 변환합니다. 게임 UI 배율이 다르면 정지 후 **UI 배율 보정**을 조절합니다. 모든 해상도·UI 배치의 인식 품질을 보장하는 자동 보정은 아닙니다.
- 앱이 관측하지 못한 순간의 캐릭터 전환은 식별하지 못합니다. 전환 메뉴를 너무 빨리 닫거나 캡처가 멈춘 동안 캐릭터를 변경한 경우, 일반 ESC 메뉴에서 이름을 다시 확인한 뒤 플레이해주세요.
- CPU 분석을 사용합니다. 실제 처리 속도는 앱에 표시됩니다. CPU 성능이 낮아 관측 사이 간격이 5초를 넘으면 연속 관측 후보가 초기화됩니다.
- Google Drive 업로드는 이번 실행 파일에 연결하지 않았습니다.

## 검증 결과와 한계

실행한 검증: 기존 테스트와 라이브 연결 테스트 총 45개 통과, Mac의 Qt offscreen UI 생성·삭제 버튼·화면 렌더링 검사 통과. Windows DLL 및 아카이브 구성은 정적 검사합니다.

아직 실행하지 않은 검증: 최신 내장 OBS를 포함한 EXE 재빌드와 Windows 실행, 다양한 해상도의 OCR/탐지, 게임 성능 영향. 이 문서의 기존 45개 테스트 결과는 최초 빌드 시점의 기록입니다. 현재 내장 OBS 엔진의 Windows 실측과 최신 검증은 [내장 OBS 안내](50-embedded-obs.md)를 참고합니다. 실행되지 않으면 `%LOCALAPPDATA%\BeatricePC\startup-error.log`, 분석 오류라면 `errors.log`와 `runtime.log`를 확인합니다.

## 재현

`packaging/requirements-windows.txt`의 Windows 휠, 공식 Windows embedded Python 3.12.10, LZMA SDK를 준비한 뒤 `packaging/build_single_exe.py`를 실행합니다. Python 모듈·모델·라이브러리를 7-Zip SFX에 넣는 방식입니다. 생성물과 라이브러리 목록/해시는 패키지 내부 `package-manifest.json`, EXE 해시는 `dist/BeatricePC.exe.sha256`에 있습니다. 압축 빌드 자체를 Windows 실행 검증으로 취급하지 않습니다.

구성 근거: [Python embedded 배포 문서](https://docs.python.org/3.12/using/windows.html#the-embeddable-package), [7-Zip LZMA SDK](https://www.7-zip.org/sdk.html). 오픈소스 라이브러리의 라이선스 파일은 배포 휠의 metadata와 함께 포함합니다.
