# 주간 관문 기록 UI

2026-10-08, `ui-ux-pro-max`를 포함한 프리뷰 검토 후 사용자가 승인한 디자인을 적용했습니다.

## 기록 표시

- 한국 시간 수요일 06:00 이상, 다음 수요일 06:00 미만을 한 주로 봅니다.
- 왼쪽 화살표는 이전 주, 오른쪽 화살표는 다음 주입니다. 이번 주에서는 오른쪽 버튼이 비활성화됩니다.
- 가운데에는 `yyyy. M. d ~ yyyy. M. d` 날짜 범위만 표시합니다. 마지막 날짜는 오전 06시의 제외 경계입니다.
- 선택한 주는 보상표 등 다른 메뉴를 다녀와도 유지합니다. 새 주가 시작되면 이번 주 화면은 갱신하고, 과거 주를 보고 있다면 그 주를 유지합니다.
- 날짜별 `yyyy년 M월 d일` 구분선과 클리어 시각을 최신순으로 표시합니다.
- 로그 문장: `{캐릭터명}이/가 {던전명} {난이도} {관문}을/를 클리어했습니다.`
- 관문 없는 완료의 `레이드 전체` 표시는 생략합니다. 예: `후이수가 에키드나 하드를 클리어했습니다.`
- 은/는·이/가·을/를은 한글 종성에 따라 선택합니다. 숫자와 영문 끝 글자는 발음 추정 규칙을 사용하므로 모든 외국어 발음을 보장하지 않습니다.
- 로그 클릭으로 기존 골드·비용·귀속 비율 상세 창을 엽니다. 기록의 저장 시각·매칭 결정은 변경하지 않습니다.
- 해당 주가 비어 있으면 빈 상태를 표시합니다. 해석할 수 없는 날짜는 이번 주의 `날짜 확인 불가` 영역에 남깁니다.

## 최종 디자인 기준

| 항목 | 값 |
|---|---|
| 모든 텍스트 | 내장 Pretendard 1.3.9 |
| 본문 제목·설정 섹션·상세 창 제목 | 20px |
| 주간 범위·로그 문장 | 14px |
| 시각·날짜 구분선 | 12px |
| 캐릭터명 | `characterAccent` / `#F2B995`, SemiBold |
| 던전명 | `text`, SemiBold |
| 난이도 | `accent` |
| 로그 정렬 | 시각과 문장의 수직 중앙, Tight 텍스트 경계 |
| 주간 화살표 | 44px 원형 클릭 영역 / 20px 아이콘 |
| 주간 날짜 영역 위·아래 | 각각 12px |
| 시간 열 / 문장과 간격 | 42px / 12px |
| 로그 패딩 / 최소 높이 | 좌우 4px, 위아래 10px / 44px |
| 이후 날짜 구분선 위·아래 | 20px / 12px |

상단 이름은 Beatrice입니다. 관문 기록과 보상표는 첫 메인 버튼의 하위 메뉴이므로 두 화면 모두 메인 선택 표시를 유지합니다. 선택 중인 메인 분류나 같은 하위 메뉴를 다시 눌러도 현재 상태를 보존합니다.

고정 사이드바 너비와 본문 좌우 16px을 유지합니다. 좁은 본문에서는 날짜 이동과 로그 시간·문장을 쌓아 표시합니다. 하단 캐릭터 패널과 설정 오버레이의 기존 동작은 유지합니다.

2026-10-09: 캐릭터 영역의 상하 Margin은 4px, 최소 높이는 48px로 줄였습니다. 40px 이미지 기준 실제 상하 여백은 각각 8px이며, 좌우 Margin 8px은 유지합니다.

## 소스와 에셋

- `ui/Beatrice.App/MainWindow.Records.cs`: 로그, 주간 이동, 날짜 구분선, 반응형 배치.
- `ui/Beatrice.App/RecordPresentation.cs`: 한국 시간, 주간 경계, 날짜 해석, 조사와 문장.
- `ui/Beatrice.App/Assets/tokens.json`: 최종 디자인 토큰. 이전 카드 전용 토큰은 제거했습니다.
- `ui/Beatrice.App/Assets/fonts/`: Regular·SemiBold, 원본 OFL 라이선스와 출처. 미사용 Bold 파일은 제외했습니다.
- `ui/Beatrice.App/Assets/demo.json`: 네이티브 검증용 샘플. 실제 사용자 DB와 별개이며 일반 실행에서는 사용하지 않습니다.
- `ui/Beatrice.Presentation.Tests/`: 외부 테스트 패키지 없는 .NET 검증 실행기.

프리뷰 HTML·PNG, 모델, 사용자 DB, 인증 정보, 스킬 설치본, 테스트 `bin/obj` 및 빌드 산출물은 커밋에 포함하지 않습니다.

## 2026-10-10 설정 텍스트 메뉴

설정 좌측 목록은 아이콘 대신 14px 텍스트와 12px 분류 제목을 사용합니다. `앱 관리`에는 게임 클라이언트·공용 데이터·기록 관리, `계정 및 연동`에는 Google Drive를 배치했습니다. 메뉴를 누르면 오른쪽에 해당 설정 화면만 표시합니다. 게임 클라이언트·공용 데이터·기록 관리·Google Drive는 각각 별도 화면이며, 메뉴를 전환하면 새 화면의 상단부터 표시합니다. 동일 메뉴를 다시 누르면 화면과 입력·스크롤 상태를 유지합니다. 설정을 닫았다 다시 열면 마지막 선택 메뉴를 유지합니다. 좁은 창에서도 텍스트 메뉴를 유지하도록 메뉴 너비는 기본 208px / 축소 176px / 작은 화면 120px이며, 메뉴 자체를 세로로 스크롤할 수 있습니다. 기존 오버레이·Esc/X 닫기·Drive 기능은 유지합니다.

### 2026-10-10 Lost Ark API Key 설정
- 계정 및 연동 분류에 로스트아크 독립 화면 추가. 기존 컬러 에셋과 Pretendard, 20px 제목을 사용한다.
- 이름이 표시된 마스킹 입력과 저장 결과를 제공한다. Enter 또는 포커스 이동 시 자동 저장하며 설정 닫기·메뉴 전환·앱 종료에서도 입력을 저장한다. 빈 입력은 기존 키를 지우지 않으며 성공 시 입력란을 비운다. 입력 높이 44px, 좌우 패딩 12px, 세로 가운데 정렬을 사용한다.
- `%LOCALAPPDATA%/BeatricePC/lostark-api-key.bin`에 Windows DPAPI로 암호화해 저장한다. 기존 키 변경은 원자적으로 처리하며 실패하면 기존 키를 유지한다.
- 스냅샷에는 저장 여부와 안내 문구만 전달한다. Google Cloud 공용 데이터 키와 분리하며 API 요청/유효성 검사는 수행하지 않는다.

- 로스트아크 화면의 입력창 아래 고정 안내를 제거한다. 작업 결과는 검증·초기화 버튼 아래에서만 표시한다.
- 검증 버튼은 추후 구현 예정으로 비활성화하며 네트워크 검증 코드는 포함하지 않는다. 초기화는 입력란과 이 PC에 저장된 로스트아크 키만 비운다. Google 계정과 기록은 유지한다.
