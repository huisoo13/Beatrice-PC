# 게임 화면 오버레이 재작업 메모

2026-10-07. 사용자의 요청으로 오버레이 프로토타입의 실행 코드·설정 UI·전용 테스트·미리보기 도구를 모두 제거했다. 이 문서는 나중에 다시 설계할 때 참고할 구조와 요구사항만 보존한다. 현재 앱에는 게임 화면 오버레이 기능이 없다.

제거 후 기존 회귀 테스트 301개가 통과했다. Windows DPAPI 검사를 포함해 샌드박스 밖에서 실행했고, 실행 코드·테스트·도구에 HUD 전용 참조가 남아 있지 않은지 확인했다.

## 제거 범위

- 별도 투명 창과 표시 상태 모듈: overlay_ui.py, overlay_state.py.
- 기존 앱의 ON/OFF 토글, 위치·크기 설정, 미리보기 및 창 수명 관리 연결.
- 전용 테스트 2개 파일과 미리보기 생성 도구·이미지·컴파일 캐시.
- 오버레이를 위해 추가한 게임 창 좌표·모니터 DPI 변환 함수.
- 임시 기록 귀속 알림 큐, 표시용 안정화 관문 배열 보완, 캐릭터 변경 중 플래그 추가.

기존 인식·캡처·저장 동작으로 되돌렸다. 일반 완료 이벤트와 임시 기록의 캐릭터 귀속 저장 기능 자체는 기존대로 동작한다. Run-Beatrice.cmd의 관리자 권한 실행 통합은 유지한다. 이전 실행에서 생성한 사용자 데이터 폴더의 overlay-settings.json은 읽지 않으며, 재작업 시 새 설정 정책을 결정한다.

completion_overlay.py, completion-overlay.pt 및 해당 설정·테스트는 게임 내 완료 연출을 인식하는 기존 기능이다. 삭제한 앱 HUD와 다른 기능이므로 유지한다.

## 다시 구현할 때의 구조

기존 Worker.observation 결과를 메인 UI와 오버레이가 공유한다. 오버레이용 OCR·모델·OBS 캡처를 중복 실행하지 않는다. 표시용 상태 변환과 Qt 창을 분리한다.

별도 PySide6 최상위 창에 투명 배경, 테두리 제거, 최상위 표시, 입력 통과, 포커스 비수신 설정을 적용한다. 메인 창을 최소화해도 HUD가 유지되도록 네이티브 소유 창 관계를 피하고, 종료·재시작 때 수명을 명시적으로 관리한다.

선택한 게임 창이 활성일 때만 표시한다. Alt+Tab·게임 최소화·종료 때 숨긴다. 게임의 클라이언트 영역을 기준으로 모서리 위치를 계산하고, Windows 물리 좌표와 Qt 논리 좌표를 모니터별 DPI로 변환한다. 대상·세대 변경 때 이전 표시 상태를 초기화한다. 위치 추적은 가벼운 타이머로, 내용 갱신은 기존 관측 이벤트로 처리한다.

## 마지막으로 합의한 표시 요구사항

상태 점과 캐릭터 텍스트를 한 줄로 표시한다. 줄바꿈하지 않고 내용 너비에 맞춘다. 상태 점 색은 초록=최근 분석 결과 수신, 회색=대기·정지, 빨강=오류다. 이전 프로토타입은 분석 결과가 5초 이상 갱신되지 않으면 회색으로 전환했다. 노란 상태와 OBS 검은 화면 안내 등 상태별 문구는 표시하지 않는다.

캐릭터 텍스트의 우선순위:

1. 로그인 캐릭터 선택 화면: `캐릭터 선택 중`.
2. 캐릭터 변경 중: `캐릭터 변경 중`. 변경 대상 이름을 못 읽어도 실제 변경 상태를 기준으로 한다.
3. 캐릭터 확정 후: 캐릭터명만 표시한다.
4. 그 외 미확정: `ESC 메뉴를 열어 캐릭터를 확정 시켜주세요.`.

최초 요구에는 던전·난이도·관문과 기록 완료 토스트가 있었지만, 마지막 표시 수정에서는 캐릭터 한 줄로 축소했다. 재작업 시 이를 다시 추가할지는 사용자와 범위를 정한다.

## 던전·토스트를 다시 추가할 때

현재 관문은 메모리의 안정화된 배열에서 진행 중 관문을 읽는다. DB는 완료 기록용이므로 현재 진행 표시의 근거로 사용하지 않는다. 완료된 관문 다음 번호를 임의로 추측하지 않는다. 던전 유지 정보와 새로 확인한 정보를 구분하고, 대상이나 캐릭터가 바뀔 때 오래된 정보를 초기화한다.

일반 완료는 기존 result.events를 사용한다. 이는 저장 성공 후 전달되는 이벤트다. result.pendingEvents는 캐릭터 미확정 임시 저장으로 구분한다. 현재 임시 기록을 확정된 캐릭터에 귀속시키는 경로는 일반 완료 이벤트를 전달하지 않는다. 알림이 필요하면 전체 트랜잭션 커밋 후 새로 저장된 기록만 이벤트로 전달하도록 다시 보완한다. 저장 실패·기존 완료·Drive 복원·시작 시 DB 조회로 완료 토스트를 발생시키지 않는다.

이전 토스트 설계는 중복 방지, 한 번에 저장된 관문 묶기, 표시 4초, 대기열 최대 8개였다. 비활성 게임에서 발생한 토스트를 복귀 후 재생하지 않았다.

## 재작업 검증 항목

- 기존 인식·저장 회귀 테스트.
- 캐릭터 선택·변경·확정·미확정 표시와 후보 이름 미노출.
- 상태 점 색, 한 줄 배치, 한글·긴 안내 문구·크기 변경 렌더.
- 실제 게임 클릭·키보드 입력 통과와 포커스 유지.
- 게임 창 이동·크기 변경, 다중 모니터·배율 변경, Alt+Tab·최소화·종료·앱 재시작.
- OBS 캡처에 HUD가 섞이지 않는지 확인.
- 토스트 재추가 시 커밋 후 이벤트, 롤백 시 미전달, 임시 기록 귀속과 중복 방지.

사용자가 이전 프로토타입의 실게임 표시를 확인했다. 독점 전체화면·다중 모니터 DPI 및 입력 통과 전체 시나리오는 충분히 검증하지 않았다. 이전 오버레이는 단일 EXE로 재빌드하지 않았다. 재작업은 창 모드·테두리 없는 창 모드부터 검증한다.
