# 매칭 모드 던전 탐지 보완

후속 전투·완료 인식과 현재 모델은 [관문 기록 보완](27-gate-completion-recovery.md)을 확인합니다. 아래는 입장 화면 보완 당시의 검증 기록입니다.

2026-09-23. 캐릭터 인식은 유지하고 실제 세르카 진단 기록으로 던전 탐지를 보완했습니다.

## 확인한 원인

`outputs/dungeon-review-0923`에 보존한 기록의 1587·1595·1603 프레임에서 던전 패널 자체는 약 0.96 신뢰도로 탐지됐지만 `gate_panel`은 누락됐습니다. 따라서 `gate_panel_missing_or_outside`로 종료되어 OCR을 실행하지 않았습니다. 기존 던전 역할 모델의 양성 학습 이미지는 한 장뿐이었습니다.

또한 실제 화면의 `[매칭 모드]`가 `supportedDifficulties`에 없었습니다. 관문 탐지만 복구해도 난이도 검증에서 거절되는 별도 원인입니다. 매칭 모드를 지원 목록에 추가했으며 노말이나 하드로 추측하여 바꾸지 않습니다. 던전 이름 목록은 여전히 OCR 제한에 사용하지 않습니다.

## 학습 자료와 범위

`data/annotations/dungeon-matching-0923.json`은 기존 17장에 세르카 내부 3장(1587·1590·1593), 입장 전 선택·로딩 등 음성 4장(1547·1555·1571·1579)을 추가한 24장입니다. 총 양성 4장, 음성 20장입니다. 새 원본은 `data/raw/dungeon-matching-0923`에 있습니다.

던전 패널 라벨은 제목·모드·관문이 들어 있는 상단 기능 영역입니다. 세르카 화면의 골드 보상 안내까지 박스를 늘리면 기존 내부 상대 좌표와 맞지 않으므로 포함하지 않습니다. 관문 영역은 아이콘 행을 포함합니다. 이 좌표는 학습 라벨이며 실행 중에는 YOLO가 영역을 탐지합니다. 내부 제목·모드의 상대 배치 가정은 남아 있습니다.

추가 학습 후 기존 1막 재생에서 패널 상단이 실제보다 약 10픽셀 아래로 잡혀 제목 윗부분이 잘렸습니다. `config/dungeon-panel.json`의 제목 상단 여유를 패널 높이의 0.12에서 0.07로 넓혀 해결했습니다. 작은 탐지 위치 오차를 허용하되 고정 화면 좌표로 대체하지 않습니다.

기존 던전 모델에서 CPU, 이미지 크기 1280, freeze 10, 학습률 0.001, 50 epoch로 추가 학습했습니다. 실행명은 `dungeon-matching-0923`입니다. 신뢰도 기준 0.7과 관문 포함 관계 검증은 낮추거나 제거하지 않았습니다. 캐릭터 모델, 캐릭터 OCR 처리, 관문 상태 모델, 확정 정보의 10초 유지 정책은 이번 수정 대상이 아닙니다.

## 검증 범위

학습 자료와 같은 세션의 다른 프레임 재생은 독립 정확도 평가가 아닙니다. 별도 세션의 기존 1막 기록과 기존 재현 검사도 함께 확인합니다. 모든 자료는 3440×1440이며 다른 해상도 검증은 남아 있습니다.

- 세르카 1583~1611 연속 29프레임에서 이름과 매칭 모드를 모두 확인했습니다. 이 중 3장은 학습에 포함됐고 26장은 같은 세션의 미학습 프레임입니다. 1585 프레임부터 표시가 확정됐습니다.
- 학습에 추가하지 않은 별도 세션의 1막 7프레임에서 이름과 싱글 모드를 모두 읽었습니다.
- 입장 전 선택, 로딩, 일반 화면 등 19프레임에서 던전 표시 오탐이 없었습니다. 이 중 4장은 추가 학습한 음성 화면입니다.
- 원본 프레임부터 캐릭터/던전 YOLO, 관문 상태 YOLO, OCR, 시간 안정화를 다시 실행한 총 55개 검사 모두 통과했습니다. 결과는 `outputs/dungeon-review-0923/audit-result.json`에 있습니다.
- 자동 테스트 90개가 통과했습니다. 매칭 모드를 그대로 유지하는 회귀 검사를 추가했습니다.
- 기존 재현 검사에서도 32/32 영역 일치, 추가 오탐 0, 기능 11개와 전환 시나리오 6개, 별도 일반 화면 4개 검사를 통과했습니다. 결과는 `outputs/dungeon-matching-regression-final/report.json`에 있습니다.

검증한 모델을 `models/dungeon-regions.pt`로 활성화했습니다. SHA256은 `752778636982ad5c714350ed9c2ebca2faf8056af3da1388d9f5378b97aedd6e`이며 설정 파일에도 기록했습니다. 캐릭터 가중치가 기존 SHA256과 동일한지 확인했습니다.

이번 기록에는 관문/난이도 HUD가 없는 `증명 5단계` 화면도 있습니다. 해당 화면은 현재 관문 기록용 탐지 구조의 대상이 아니며, 이 작업으로 그 콘텐츠의 별도 HUD까지 지원하게 된 것은 아닙니다.

기존 던전 가중치는 `outputs/dungeon-review-0923/dungeon-before.pt`에 보존했습니다. 모델과 원본 이미지, 진단 출력은 Git 제외 대상입니다. 적용 후 앱을 완전히 종료하고 `Run-Beatrice.cmd`로 다시 실행해야 새 가중치와 모드 설정이 로드됩니다.
