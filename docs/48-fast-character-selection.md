# 최초 선택 캐릭터 변경 시 이전 이름 확정 방지

후속: 어두운 화면 미탐지는 [10월 6일 추가 학습](49-dim-character-selection.md)으로
보강했다. 아래는 보호 로직만 추가했던 당시 기록이다.

2026-10-01 진단 기록: `outputs/fast-selection-20261001-234948` (42프레임).
후이수 확인 후 테베체, 힐레우스로 선택 카드가 바뀌었지만 이름 영역 미탐지로
이전 접속 후보가 남아 로딩 종료 후 후이수로 잘못 확정되었다.

## 변경

- 관측에 YOLO가 탐지한 선택 카드 박스를 전달한다.
- 직전 카드와 현재 카드의 교집합이 작은 박스 면적의 절반 미만이면 선택 변경으로
  처리하고 이름 후보, 확인 횟수, 확정 대상을 모두 해제한다. 화면 고정 좌표는 없다.
- 같은 카드의 작은 탐지 흔들림이나 비밀번호 창 때문에 이름이 가려진 경우는
  기존 후보를 유지한다. 새 카드는 자체 연속 확인이 필요하다.
- 카드 내부 재탐지가 실패해도 전체 화면에서 찾은 유효한 카드 내부 이름은 보존한다.
- 모델, 클래스, 가중치는 변경하지 않았다. 추가 여백 재탐지는 경계 변화에 불안정하여
  채택하지 않았다.

## 검증과 한계

수정 중 42프레임 재생에서 이전 이름 확정이 차단되었고, 기존 47프레임 정상 접속
기록은 후이수로 확정되었다. 선택 변경/이름 미탐지, 같은 카드 흔들림,
새 카드 독립 확인에 대한 회귀 테스트를 추가했다.

빠른 선택 기록의 새 이름 미탐지 자체는 아직 해결되지 않았다. 충분히 읽지 못하고
입장하면 확인 대기로 남으며 메뉴 인식으로 복구할 수 있다. 다양한 선택 카드와 이름을
추가 학습하고 별도 기록으로 검증해야 한다. 카드 위치가 그대로인 페이지 변경 등은
박스 겹침만으로 검출할 수 없으므로 추가 보강 대상이다.
