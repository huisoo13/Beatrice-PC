# 산출물 정리와 최종 통합 검증

2026-09-25. EasyOCR·좌표식 OCR·인식 레거시 제거 이후, 앞서 확인한 불필요 산출물까지 정리하고 현재 활성 설정으로 검증했습니다.

## 실제 정리

28개 파일·디렉터리 경로, 합계 **846.16 MiB**를 삭제했습니다.

- 이전 `raid-banner-0924`, `raid-banner-header-0924` 학습 변환 데이터셋
- 미선택 `intermediate.pt`, `intermediate-19.pt`, `intermediate-38.pt`
- 중간 bootstrap 이미지, 중간 OCR 검사 스크립트·결과, 이전 재생 결과·로그
- `candidate-dungeon.json`, `candidate-ui.json` 임시 설정
- gated/gateless/normal 재생용 중복 입력 폴더

중복 입력은 원본과 모든 파일의 SHA-256이 일치함을 확인한 후 삭제했습니다. 삭제 전 절대 경로가 작업 공간의 `outputs/` 또는 `data/datasets/` 내부인지 검사했습니다. 실제 경로별 크기는 `outputs/cleanup-0925/removed-files.json`에 남겼으며, 삭제 후 대상이 모두 없어졌는지도 확인했습니다.

활성 YOLO 3개와 PaddleOCR 모델, 직전 던전 복구 모델, 최종 학습 초기값 `intermediate-27.pt`, 최종 학습 자료·원본·라벨·검증 결과는 보존했습니다. 그 외 과거 모델·라벨은 학습 계보 및 복구 자료로 남아 있습니다. 원본 자료를 포함한 `outputs/` 전체를 지우지는 않았으며 사용자 DB도 변경하지 않았습니다.

## 복사본 없는 재검증

`tools/replay_recognition_diagnostics.py`에 `--sequence-from`과 `--sequence-to`를 추가했습니다. 원본 진단 폴더에서 시작·끝 sequence를 포함하는 구간을 선택하며, 선택 결과가 비어 있으면 오류로 처리합니다. 기존 복사본 없이 같은 구간을 재생할 수 있습니다. 로컬 55개 회귀 검사도 임시 candidate 설정 대신 현재 활성 설정을 읽도록 변경했습니다.
