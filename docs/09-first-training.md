# YOLO26n 첫 학습과 한 장 추론

이번 단계는 검수된 이미지 10장·26박스로 학습부터 이미지 예측까지 연결하는 기능 확인이다. OCR, 실시간 영상 상태 관리, 관문 슬롯 확정, DB 저장은 아직 구현하지 않는다.

## 실행 환경

Mac의 별도 `.venv-ml`을 Python 3.12.14로 구성했다. 처음 제안한 3.11 대신 사용 가능한 번들 3.12를 사용한 변경이며 Windows 3.11 설치는 아직 미검증이다. 실제 설치 버전은 requirements-ml-macos-observed.txt에 기록했다. 다른 운영체제에서는 이 Mac 의존성 목록을 그대로 설치하지 않는다.

PyTorch는 학습 계산 엔진이고 Ultralytics는 YOLO26n의 학습·추론 인터페이스다. 앱에 포함할 Core ML 모델을 만드는 과정과 비슷하며, 가중치 파일은 학습 결과인 숫자 파라미터 묶음이다. 최초 yolo26n.pt는 게임 아이콘을 아직 모르는 사전학습 모델이다.

## 데이터 구성

원본 좌표 ROI는 [32,112,352,224], 크기는 320×112다. 모든 승인 박스를 포함하는지 검사하고 YOLO의 0~1 좌표로 변환했다. 다시 원본 좌표로 복원하여 0.001픽셀 이내 일치를 확인했다. 원본 3440×1440을 기준으로 하며 다른 해상도는 현재 오류 처리한다. 같은 해상도라도 UI 배율·위치가 달라지면 ROI가 어긋날 수 있어 지원을 보장하지 않는다.

학습 입력 크기는 320이다. 정사각형 입력을 만들 때 비율을 유지한 패딩은 라이브러리가 처리한다. 좌우 반전·회전·모자이크는 끄고 작은 위치/크기/밝기 변화를 사용한다. 첫 기능 확인에서는 특징 추출부 일부를 동결(freeze=10)해 미리 학습한 특징을 유지하고 탐지 부분을 중심으로 학습한다.

**독립 평가 데이터는 없다.** dataset.yaml의 val은 도구가 요구하는 경로를 충족하기 위해 train과 같은 images를 가리킨다. 두 데이터가 독립인 척 분할하거나 복사하지 않았다. 로그에 출력된 mAP·정밀도·재현율은 학습 데이터 재관측값이므로 실제 정확도로 보고하지 않는다. 학습용/검증용/평가용 세션 분리는 별도 데이터 확보 후 진행한다. 아이콘이 없는 음성 사례도 아직 학습에 포함되지 않았다.

## 실행

프로젝트 폴더에서 실행한다.

```bash
.venv-ml/bin/python tools/yolo_first.py prepare
.venv-ml/bin/python tools/yolo_first.py train --epochs 80 --device cpu
```

prepare는 승인 JSON과 원본 해시를 확인하고 ROI 이미지·정답·출처 목록을 생성한다. train은 yolo26n.pt에서 학습한다. epoch는 모든 학습 이미지를 한 번씩 사용하는 단위이며 같은 10장을 반복해서 학습한다. 이는 새 이미지 800장을 얻는 것과 다르다. 재실행하면 학습 출력 폴더 이름에 번호가 붙을 수 있으므로 출력된 경로를 확인한다.

```bash
.venv-ml/bin/python tools/yolo_first.py predict data/raw/SAMPLE_006.jpg --weights models/gates-yolo26n-first.pt --output outputs/prediction-sample006
```

결과 prediction.png에는 모델 예측 박스·상태·신뢰도가 표시된다. observation.json에는 원본 화면 좌표의 박스, 상태별 개수, ROI, 모델 경로가 저장된다. Windows에서 그림을 저장할 때는 `--font`로 한국어 지원 글꼴 경로를 지정한다.

예측 함수는 ROI의 BGR 배열을 모델에 전달한다. 따라서 이후 영상·dxcam도 같은 색상 순서와 ROI 전처리로 연결할 수 있다. 지금은 파일 입력 명령만 구현했다.

탐지 순서만으로 관문 번호를 확정하지 않는다. 누락된 아이콘이 있으면 순서가 바뀔 수 있기 때문이다. 현재 결과는 관문 상태 이벤트가 아닌 프레임 관측이며 gateIdentityStatus=not_validated, eventConfirmed=false다. 추론 호출 시간에는 첫 실행 준비가 포함될 수 있고 이미지 로딩·모델 로딩은 제외하므로 실시간 지연이나 게임 성능 영향의 측정값이 아니다.

## 결과 확인

정답 라벨을 사용해 예측을 만들지 않는다. predict 명령은 이미지와 학습 가중치만 읽는다. 학습 이미지의 예측과 정답을 비교해 첫 연결 상태를 확인하되 실서비스 정확도를 주장하지 않는다. 완료 여부를 확정하는 상태 관리와 OCR은 후속 단계다.

## 실제 실행 결과

- Python 3.12.14 / Ultralytics 8.4.152 / PyTorch 2.14.0, Apple M4 CPU에서 80 epoch 완료. 로그상 학습 시간은 약 54초이며 설치·초기화 시간은 제외된다.
- 학습 마지막 가중치 last.pt를 models/gates-yolo26n-first.pt로 보존했다. 동일 학습 데이터의 best 지표로 추가 모델 선택을 하지 않았다.
- SAMPLE_006 예측: 완료 2, 진행중 1, 진행 전 1. 한국어 표시 이미지와 JSON을 저장하고 직접 확인했다.
- 학습 이미지 10장 재관측: IoU 0.5 이상에서 정답 26개 모두 대응, 추가 박스 0, 상태 혼동 0. 신뢰도 임계값 0.25, NMS IoU 0.5 사용. 이는 학습 데이터 재확인 결과이고 독립 성능 평가가 아니다.
- 상세 재관측 결과는 outputs/training-reconstruction.json, 실행 코드는 tools/check_training_predictions.py다.
- 첫 SAMPLE_006 예측 호출은 약 560ms였으나 초기 실행 준비가 포함돼 반복 추론 속도로 해석하지 않는다. 게임 성능 영향·실시간 기록 지연·OCR은 미검증이다.
