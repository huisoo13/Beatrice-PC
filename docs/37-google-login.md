# Google 로그인

2026-09-27: 메인 창 상단에 Google 로그인, 로그아웃을 추가했습니다. 로그인 후에는 로그인 버튼을 숨기고 이메일과 로그아웃만 표시합니다.
최초 구현은 로그인만 지원했으며, 이후 [Drive 저장·불러오기](38-google-drive.md)를 추가했습니다.

## 실행과 설정

- 프로젝트 최상단에 Google Cloud에서 받은 데스크톱용 `client_secret_*.json` 하나를 둡니다.
- 다른 위치를 사용하려면 `BEATRICE_GOOGLE_CLIENT_FILE`에 JSON 경로를 설정합니다.
- PC와 iOS 클라이언트는 같은 Google Cloud 프로젝트에 등록하되 각자의 클라이언트 ID를 사용합니다.
- 앱을 완전히 재시작하고 메인 창 상단의 `Google 로그인`을 누릅니다.
- 기본 브라우저에서 계정을 선택하고 동의하면 앱에 이메일이 표시됩니다.
- 브라우저 인증 응답을 받으면 해당 탭 자동 닫기를 시도합니다. 브라우저 정책으로 차단되면 탭을 닫고 앱으로 돌아가라는 안내가 표시됩니다. 최종 로그인 성공 여부는 앱에서 확인합니다.
- 클라이언트 설정 파일은 Git에서 제외합니다. 현재 패키징 스크립트는 이 파일을 자동으로 복사하지 않으므로 배포 시 앱 폴더에 별도로 배치하거나 환경 변수로 지정해야 합니다.

## 동작

Python 표준 라이브러리로 Google의 데스크톱 Authorization Code 흐름을 사용합니다.
시스템 브라우저와 임의 포트의 127.0.0.1 리스너, 요청별 state, PKCE S256을 사용합니다.
콜백은 state와 경로를 검사하고 코드 교환 후 Google UserInfo 응답에서 계정을 확인합니다.
최초 로그인 범위는 `openid email profile`이었으며, 현재는 앱 전용 Drive 권한도 요청합니다.
기존 로그인은 별도 `Drive 권한 연결`로 확장할 수 있습니다.

로그인 대기는 최대 3분이고 HTTP 요청은 각각 15초 제한입니다.
브라우저를 닫았다면 앱의 `로그인 취소`를 누르면 됩니다.
네트워크 작업은 별도 스레드에서 수행합니다. 취소·새로고침·앱 종료 후 도착한 결과는 저장하지 않습니다.

갱신 토큰과 계정 정보는 데이터 디렉터리(기본 `%USERPROFILE%\BeatricePC`)의
`google-session.bin`에 Windows DPAPI로 암호화하여 원자적으로 저장합니다.
평문 저장으로 대체하지 않으며, 인증 코드·토큰·콜백 URL은 로그에 남기지 않습니다.
재실행 시 갱신 토큰으로 계정을 확인한 뒤 로그인 상태를 표시합니다.
오프라인이거나 인증이 만료되면 오류와 재로그인 버튼을 표시하고 기존 저장 정보는 유지합니다.
로그아웃은 이 PC의 저장 정보만 삭제하며 Google 계정의 앱 권한을 취소하지 않습니다.

## 검증

`tests/test_google_auth.py`: 설정 형식, 잘못된 state, 거부 응답, 실제 로컬 HTTP 콜백과 PKCE,
취소/시간 초과, 토큰 갱신, Windows DPAPI 저장·복원·삭제, UI 취소 후 늦은 응답 무시,
로그인 표시·로그아웃을 검사합니다. 외부 Google 응답은 모의 처리합니다.
실제 Google 계정의 브라우저 로그인은 사용자 확인이 필요합니다.

공식 프로토콜: https://developers.google.com/identity/protocols/oauth2/native-app
