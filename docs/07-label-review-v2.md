# 추가 이미지 검수

사용자가 제공한 SAMPLE_001~007을 원본 크기 3440×1440으로 확인했다. SAMPLE_006은 기존 파일과 SHA256이 같아 중복 추가하지 않았다. 새 이미지 6장을 원본 바이트 그대로 보존하고 `data/annotations/review-v2.json`에 박스 16개를 수작업 초안으로 기록했다. review-v1의 승인 라벨은 변경하지 않았다.

| SAMPLE_005 | 진행중 / 진행 전 / 진행 전 / 진행 전 |
| SAMPLE_007 | 완료 / 완료 / 완료 / 완료 |

총 완료 11, 진행중 2, 진행 전 3개다. 기존 승인 자료 4장·10박스에 더하면 고유 이미지 10장·26박스가 되지만, 신규 6장·16박스는 아직 pending이다. 학습용 txt로 내보내거나 학습에 넣지 않았다.

검수 결과물: `outputs/label-review-v2/review-grid.png`, 파일별 `S001.png` 등. Python 렌더러로 좌표 범위와 원본 크기를 확인하고 출력 이미지를 직접 열어 박스·한국어 표시를 검토했다. 모델 추론은 실행하지 않았다.

촬영 세션의 독립성은 아직 확인하지 못했으므로 신규 자료를 임시 하나의 그룹으로 관리한다. 학습·검증·최종 평가 분할을 확정하지 않았고 별도 촬영이라는 이유만으로 독립 평가 자료로 간주하지 않는다. 원본에 이미 검수한 파일과 같은 SAMPLE_006이 포함된 사실도 고려한다.

검수 시 파일명과 관문 번호로 수정 사항을 알려주면 된다. 모델 기준은 YOLO26n을 유지한다.
