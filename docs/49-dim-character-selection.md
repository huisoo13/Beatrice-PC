# 어두워진 최초 캐릭터 선택 화면 보강

## 원인과 실제 마지막 선택

2026-10-01 23:48 세션에서 비밀번호 입력창 뒤에도 이름이 보였지만
선택 카드·이름·게임 시작 버튼의 YOLO 탐지가 누락되어 OCR이 실행되지 않았다.
빠른 클릭으로 읽을 시간이 없었던 문제가 아니다.

원본 카드 줄 재검토 결과 후이수 → 테베체 → 힐레우스 → 테베체 순으로
선택이 변경되었다. 비밀번호 입력 중 파란 선택 표시가 있는 카드는 **테베체**다.
이전 설명에서 힐레우스를 마지막 선택으로 본 것은 정정한다.

## 학습 자료

`tools/prepare_login_dim.py`가 기존 `login-marker-1001.json` 277장을 보존하고
밝은 선택 화면 3장 및 실제 비밀번호 입력 중 화면 1장을 기반으로
전체 화면 밝기 변형 32장, 카드 전체 및 경계 여백 변형 48장을 추가한다.
총 357장이다. 선택 카드, 해당 이름, 게임 시작 버튼만 추가 라벨링한다.

라벨 좌표는 오프라인 학습용이다. 런타임 고정 좌표나 이름의 고정 부분 영역은
추가하지 않는다. 기존 10클래스 캐릭터 모델을 재학습하며 새 모델은 만들지 않는다.

같은 원본의 변형과 같은 플레이 세션은 모두 학습에 속한다. 학습 데이터 재생은
수정 확인 용도이며 독립 정확도가 아니다. 별도 47프레임 접속 기록은 이번 추가
학습에 사용하지 않으나, 과거부터 개발에 사용한 기록이므로 새로운 독립 시험도 아니다.

## 적용 기준

- `tools/check_fast_selection.py`: 어두운 화면에서 잘못된 이름 없음,
  실제 입장 전에 기록 활성화 없음, 최종 테베체 확정.
- 별도 기존 접속 47프레임에서 후이수 확정 유지.
- 기존 화면 127장의 클래스 재현 결과를 교체 전과 비교.
- 전체 코드 회귀 테스트와 README 모델 표 검사.
- 이전 가중치/설정을 보존한 뒤 검증된 후보만 교체.

새 이름 확인 없이 이전 캐릭터를 확정하지 않는 보호 처리는 유지한다.
모든 해상도·이름·배경에 대한 정확도를 이 자료만으로 보장하지 않는다.
